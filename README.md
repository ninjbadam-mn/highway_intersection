# Зам·Гүүр тооцоолуур

Авто зам, гүүрийн төсөллөлтөд өдөр тутам хийгддэг тооцоонуудын вэб хэрэгсэл.

## Бүтэц

```
index.html                     Нүүр хуудас, тооцоонуудын жагсаалт
assets/site.css                Бүх хуудасны нийтлэг загвар
assets/<тооцоо>.js             Тооцоо бүрийн логик
uulzvar/zogsooh-uzegdelt.html  1.1 Зогсоох үзэгдэлтийн зай
```

## Шинэ тооцоо нэмэх

1. `uulzvar/` (эсвэл шинэ хавтас) дотор HTML хуудас нэмнэ.
2. Логикийг `assets/` дотор тусдаа `.js` файлд хийнэ.
3. `index.html` дахь жагсаалтад холбоос нэмнэ.

## Анхааруулга

Үр дүн нь лавлах зорилготой. Мөрдөгдөж буй норм, дүрэмтэй тулгаж шалгана уу.
